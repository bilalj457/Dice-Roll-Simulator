# 🎲 Dice Rolling Simulator

## About
This is a beginner-friendly Python project that simulates rolling a six-sided dice. It generates a random number between 1 and 6 and counts the total number of rolls.

I made this project to practise Python basics and improve my programming skills.

## Features
- Roll a virtual six-sided dice.
- Generate random numbers from 1 to 6.
- Count the total number of rolls.
- Roll the dice again as many times as you want.
- Handle invalid user input.

## Requirements
- Python 3

No extra libraries are needed.

## How to Run
1. Install Python 3.
2. Download or clone this repository.
3. Open the terminal in the project folder.
4. Run the following command:

   `python dice_rolling.py`

If that does not work, try:

   `python3 dice_rolling.py`

## Example Output

